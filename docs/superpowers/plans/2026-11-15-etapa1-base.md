# Etapa 1 (Base) — Plano de implementação

> **Execução:** segue o fluxo do `CLAUDE.md` do projeto. Scripts vão ao Codex (`delegar-codex`). Claude revisa, compila no Editor e roda os testes. Sem commit.

**Objetivo:** o jogo passa a guardar o que o jogador descobriu, e o caderno passa a permitir comparar duas evidências para gerar uma conclusão.

**Arquitetura:** três classes de lógica sem cena (`EstadoDaNoite`, `CatalogoDeEvidencias`, `Caderno`) em `Assets/Scripts/Historia/`, um catálogo em JSON em `Assets/Resources/Historia/evidencias.json`, o save existente estendido com um campo, e novas abas na tela do `DiarioDePistas`.

**Tecnologia:** Unity 6000.5, C#, `JsonUtility`, IMGUI (como o diário atual), NUnit em modo Editor (`Assets/Editor/Testes/`).

**Spec:** `docs/superpowers/specs/2026-11-15-historia-e-terror-design.md` (seções 6, 7 e 9, fase F0).

## Restrições globais

- Sem asmdef novo. O projeto usa `Assembly-CSharp` e `Assembly-CSharp-Editor`.
- Nomes de classes e membros em português, como no código vizinho.
- Todo texto que o jogador lê deve ser claro: frases completas, sem códigos internos.
- Codex não edita cenas, prefabs nem `.meta`.
- O save antigo (sem o campo novo) continua carregando.

## Foco de revisão

1. Save antigo, sem o campo `noite`: carrega com estado vazio, sem erro.
2. Campo `noite` corrompido: carrega com estado vazio e registra um aviso.
3. Comparar uma evidência com ela mesma: resultado `Invalida`, nada é marcado.
4. Id de evidência desconhecido em `Coletar` ou `Comparar`: retorna falso ou `Invalida`, nada é marcado.
5. Entrar em Play duas vezes com recarga de domínio desligada: o estado estático começa vazio.

**Produz:**
```csharp
public enum FaseDeDaniel { Mesa, Sombra, Obstrucao, Caca }
public static class EstadoDaNoite {
    public static event Action<string> AoMarcar;          // dispara só em fato novo
    public static FaseDeDaniel Fase { get; set; }
    public static IReadOnlyCollection<string> Fatos { get; }
    public static bool Marcar(string fato);               // true se era novo; nulo ou vazio retorna false
    public static bool Tem(string fato);
    public static void Limpar();                          // zera fatos e volta Fase para Mesa
    public static string Exportar();                      // JSON: { fase, fatos[] }
    public static void Importar(string json);             // nulo, vazio ou inválido: Limpar() (inválido também faz LogWarning)
}
```
Prefixos de fato: `ev:<id>` para evidência coletada, `con:<id>` para comparação concluída.

- [ ] Implementar `EstadoDaNoite`, com reinício estático em `RuntimeInitializeOnLoadMethod(SubsystemRegistration)`.

## Tarefa 2: Catálogo de evidências e lógica do caderno

**Arquivos:** criar `Assets/Scripts/Historia/CatalogoDeEvidencias.cs` e `Assets/Scripts/Historia/Caderno.cs`; dados em `Assets/Resources/Historia/evidencias.json` (já escrito por Claude); teste `Assets/Editor/Testes/CadernoTestes.cs`.

**Produz:**
```csharp
[Serializable] public class Evidencia { public string id, tipo, titulo, local, resumo; public bool opcional; }
[Serializable] public class ParDeEvidencias { public string a, b; }
[Serializable] public class Comparacao { public string id, tipo, titulo, texto; public ParDeEvidencias[] pares; } // tipo: "hipotese" ou "conclusao"

public class CatalogoDeEvidencias {
    public Evidencia[] evidencias; public Comparacao[] comparacoes;
    public static CatalogoDeEvidencias Carregar(string json);
    public static CatalogoDeEvidencias Padrao { get; }     // Resources.Load<TextAsset>("Historia/evidencias"), em cache
    public Evidencia Buscar(string id);                    // null se não existe
    public Comparacao ComparacaoEntre(string a, string b); // a ordem não importa; null se não há
    public List<string> Problemas();                       // ids repetidos, par com id desconhecido, par com a == b, título/resumo/texto vazio
}

public enum ResultadoDaComparacao { Nova, JaRegistrada, SemRelacao, FaltaEvidencia, Invalida }
public static class Caderno {
    public static CatalogoDeEvidencias Catalogo { get; set; } // padrão: CatalogoDeEvidencias.Padrao
    public static bool Coletar(string idEvidencia);           // marca "ev:<id>"; false se desconhecida ou repetida
    public static bool Coletou(string idEvidencia);
    public static ResultadoDaComparacao Comparar(string a, string b, out Comparacao comparacao);
    public static IEnumerable<Evidencia> Coletadas();         // na ordem do catálogo
    public static IEnumerable<Comparacao> Conclusoes();       // na ordem do catálogo
}
```
Regras de `Comparar`: `a == b` ou id desconhecido → `Invalida`; alguma das duas não coletada → `FaltaEvidencia`; sem comparação no catálogo → `SemRelacao`; já marcada → `JaRegistrada`; senão marca `con:<id>` e retorna `Nova`. Em todos os casos sem comparação, `comparacao` sai null.

- [ ] Testes com um catálogo pequeno montado no próprio teste: os cinco resultados de `Comparar`; ordem invertida (`b`, `a`) acha a mesma comparação; dois pares diferentes levam à mesma conclusão e o segundo retorna `JaRegistrada`; `Coletar` de id desconhecido retorna false.
- [ ] Teste do catálogo real: `CatalogoDeEvidencias.Carregar(texto de Assets/Resources/Historia/evidencias.json).Problemas()` está vazio; `ComparacaoEntre("F02", "F01").id == "troca"`.
- [ ] Implementar as duas classes.
